About the project

From source data to a working prediction

A student-focused demonstration of the full machine learning workflow.

The problem

The system maps the original UCI Cleveland diagnosis values 0–4 into two classes: 0 means no disease recorded; 1–4 mean disease present. It accepts all 13 original input features.

Dataset

The official UCI Heart Disease dataset contains {{ metadata.source_rows }} Cleveland records in this project. Source missing values are retained and handled by imputers fitted within the training pipeline.

Workflow and algorithms

The notebook explores the data, uses an 80:20 stratified split, compares Logistic Regression, KNN, Decision Tree, and Random Forest, performs stratified cross-validation and GridSearchCV, then evaluates one selected model on the held-out test set.

The currently exported model is {{ metadata.selected_model_name }}. Flask loads the complete saved preprocessing and classification pipeline.

Technology

Python, Pandas, NumPy, scikit-learn, Matplotlib, Seaborn, Joblib, Jupyter Notebook, Flask, HTML, and CSS.

Limitations and disclaimer

The dataset is small and historical. Its measurements, labels, and population may differ from current clinical practice. Scores from this dataset are not evidence of clinical safety or generalizability. The displayed model probability is not a medically validated risk estimate. Do not use this application for diagnosis or treatment; speak with a qualified healthcare professional.
